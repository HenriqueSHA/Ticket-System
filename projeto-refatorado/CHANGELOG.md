# Changelog

All notable changes to this project are documented here ([Keep a Changelog](https://keepachangelog.com)).

## [1.1.0] - 2026-11-24 — refactored version

### Added
- Seat rescheduling (algorithm 5b): change the seat of a confirmed purchase to a free seat in the same category, atomically.
- Workspace-wide clippy pedantic lints (CI fails on any warning).
- `PROJETO`, `PREFIXO` and `VOLUME_BANCO` settings to run two copies side by side.
- Architecture, class and ER diagrams; flowcharts for algorithms 5b, 8 and 9.
- Report sections 9 to 20, 15 screenshots and a demo video generated by `ferramentas/demonstracao.mjs`.
- Bilingual README, requirements checklist and refactoring report.
- CI workflow for the refactored folder (`ci-refatorado.yml`).

### Changed
- Money parsing uses integer arithmetic only; ambiguous input such as "1.234" is rejected.
- Half-price discount is an integer percentage (`DESCONTO_MEIA = 50`).
- Report builder generates sections 8 to 20 with automatic figure numbering.

### Fixed
- New event form: suggested category names were real values, so an unused row blocked the event.
- Unchecked numeric casts in the seat map and CPF validation.
- Stale service names (`app`) in the technical README.

## [1.0.0] - 2026-11-21
- 3-container architecture, REST API, CI/CD, code review fixes and tests.
